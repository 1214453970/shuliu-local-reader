# 书留 · 本地 AI 精读

这是一个无需服务器的静态 PWA 原型：书籍留在浏览器本地，用户自己填写 OpenAI-compatible API，中译英/俄等精译请求直接从浏览器发往用户配置的中转站。

## 已实现

- 导入 EPUB、TXT（UTF-8 / GB18030 / Big5）
- IndexedDB 本地书架、阅读进度与精译缓存
- 点击段落后选择目标语言
- 自然译文、较直译版本、结构对应、翻译理由、句子主干、成分划分、应试考点、易错点、重点词/词性/词根词缀、替代译法
- 英语按五大基本句型、主谓宾定状补、从句、时态语态、非谓语等中国应试教学方式分析；俄语突出性数格、动词体与支配关系
- API 设置可从 OpenAI-compatible `/models` 接口拉取并选择模型，也保留手动填写
- 英语、俄语、日语、法语、德语、西班牙语、韩语
- PWA manifest 与 Service Worker，可添加到 iPhone 主屏幕
- 不需要本应用服务器；没有账户系统

## 本地运行

浏览器不能直接从 file:// 读取 ES Module、Service Worker 和 EPUB 文件，因此需要通过 HTTP 服务器打开。

使用任意静态服务器，例如：

- Python：python -m http.server 4173
- Node：npx serve .

然后访问 http://localhost:4173/。

## 发给朋友使用

把整个目录部署到支持 HTTPS 的静态托管即可，例如 GitHub Pages、Cloudflare Pages、Netlify 或自己的静态网站。不要把 API Key 写进代码；每个使用者都在“API 设置”里填写自己的地址、Key 和模型。部署站点必须使用 HTTPS，且中转站必须允许浏览器跨域（CORS）。

## API 设置示例

- API 地址：https://你的中转站/v1
- API Key：使用者自己的 Key
- 模型：填写地址和 Key 后可点击“拉取模型”并从列表选择；若中转站不开放 `/models`，也可手动填写

应用请求 GET /models 拉取模型列表，并请求 POST /chat/completions 完成分析，使用 OpenAI-compatible 格式。若 JSON 模式不兼容，会自动去掉 response_format 重试一次。

## 隐私边界

- 书籍正文、书架、阅读进度和精译缓存保存在当前浏览器的 IndexedDB。
- 只有点击“开始精译”时，当前段落会发送到用户自己配置的 API；勾选“参考相邻段落”后，上一段和下一段也会发送。
- API Key 保存在当前浏览器的 localStorage。不要在公共电脑上填写长期密钥。
- 浏览器清理站点数据会删除本地书架和缓存。

## 目前的边界

- EPUB 复杂排版、脚注、表格、漫画图片和扫描 PDF 尚未支持。
- 第一版不支持 PDF；后续可以增加纯文本 PDF 提取和 OCR。
- 纯前端直连 API 受 CORS 限制；模型列表和聊天接口都需要中转站允许浏览器跨域，这是“不要服务器”的交换条件。
- AI 对语法、词源和词根词缀的解释仍需人工核对，界面会尽量要求模型在不确定时留空，不要编造。
## 生词收藏与复习（v0.3）

- 阅读时打开段落精译面板，可在原文卡片输入单词/短语并收藏；AI 精译的“重点词与构词”条目也可一键收藏。
- 生词及释义、词性、例句、书名、复习进度都只保存在本机浏览器 IndexedDB；可搜索、编辑释义、删除。
- 背诵卡片采用“先回忆，再显示释义”，并可自评“忘记了 / 困难 / 认识 / 简单”。
- 间隔默认按 1、2、4、7、15、30、60 天逐步拉长；忘记时 10 分钟后再练，困难时回到较短间隔。它是便于实践的间隔复习安排，不代表唯一或精确的艾宾浩斯标准。
- 老版本升级时会保留已有书架和精译缓存，并新增生词本数据表。

## 生词本增强（v0.4）

- 可手动添加和完整编辑词条（单词/短语、释义、词性、例句）；选中书中一段文字后打开精译面板，会尝试预填选中的词语，仍可手动修改后收藏。
- 复习卡片可在“外语 → 中文”和“中文 → 外语”之间切换；显示答案后可查看词性、例句、来源。
- 生词本显示收藏数、今日到期数、累计复习数和连续学习天数。
- 可导出/恢复生词与学习记录；备份默认不含书籍。只有明确勾选“备份时包含本地书籍正文”才把书籍内容写进下载文件。恢复时重复词条和重复书籍会跳过；API 密钥不会进入备份。
- 复习答案区提供可选 AI 学习补充：生成例句、近义词辨析和小测。仅在主动点击后发送当前词条和释义到自己配置的 API，可能产生 API 费用。

## 自译、难句与逐段对照（v0.5）

- 段落精译面板可先写自己的目标语言译文，草稿自动保存在本机。点击 AI 批改才会发送该段原文和草稿到自己配置的 API，可能产生费用。AI 反馈会保存到难句记录，但不是绝对正确的标准答案。
- 精译完成后参考译文先保持折叠；主动点击“展开参考译文与讲解”才显示。已有缓存不再次计费。
- 阅读页可开启逐段对照、遮挡原文或译文；只展示本机已经精译过的段落，不会批量调用 API。点“查看结构与语法”返回对应段落面板。
- 难句本保存原文、自己的译文与批改摘要，可返回原书重做；忘记后 10 分钟再练，认识后按 1、3、7、14、30 天安排。
- 备份格式 v2 默认导出生词、难句和草稿，仍不含书籍正文与 API Key；需勾选才备份书籍。可导入旧格式 v1。若未备份原书，难句仍可查看，但重做需要重新导入对应书籍。
- 本机存储可能因清理浏览器数据、换设备或隐私模式而丢失；会定期提醒备份。

## 双向精读（v0.6）

- 阅读页设置每本书的原文语言，顶部设置目标语言；原文为外语时可选择译为中文。已导入的旧书默认按中文原文处理，可在阅读页修改，不会删除原书、旧精译、生词或难句。
- 外语译中文时，句法成分、语法规则和重点词针对外语原文讲解；自己可以先写中文译文，再请求 AI 批改。中文译外语保持原有教学逻辑。
- 段落精译缓存和难句草稿区分方向和语言；切换书籍的原文语言仅影响之后的分析。正文始终在本机；只有主动请求精译或批改时才发送相关段落到自配 API。

## 阅读导航、AI 追问与多 API 配置（v0.7）

- 阅读页提供顶部固定的上一章 / 下一章按钮、章节标签跳转，以及正文底部翻章导航；当前章节名与章节序号分开展示，避免把书名误当页码。
- TXT 导入时忽略正式章节前的独立书名/作者等前置文字；EPUB 的章节标题若与整本书书名重复，会改用章节序号显示。没有章节标记的 TXT 仍作为一个“正文”章节阅读。
- 段落精译完成后可继续围绕原文、译文、语法、词根词缀和应试判断方法向 AI 追问。对话仅在点击发送时调用 API，可能产生费用。
- API 设置支持保存多个配置，并在不同中转站、密钥和模型之间切换；旧版单一 API 设置会迁移为“默认 API”。
- API 配置（包含密钥）只保存在当前浏览器，不会进入书籍/学习记录备份；请勿在公用设备保存长期密钥。
- 升级后如网页仍显示旧界面，请强制刷新一次；Cloudflare Pages 需要重新上传本版本文件。

## 快速跳转章节（v0.8）

- 阅读页新增“快速跳转”：输入章节序号后点击“前往”，可以直接越过大量章节，不必连续点击“下一章”。
- 新增章节滑块，可拖动到大致位置，再点击或松开后跳转。
- 当前章节序号、总章节数和滑块位置会同步更新；例如可以直接跳到第 40 / 193 章。
- 原有上一章、下一章、章节标签、键盘翻页和手机左右滑动仍然保留。

## 阅读体验增强（v0.9）

- 长章节阅读时，底部提供固定的快速翻页条：可直接输入章节号跳转，或用左右按钮跨章，不必回到页面顶部。
- TXT 导入会保留正式章节标记之前的前言、书名、作者等内容，不再静默丢弃；EPUB 对仅使用 `div` 排版、带查询参数的章节路径和常见文档标题的兼容性也有所增强。
- 正文每段旁边新增本地段落笔记，可记录阅读心得、译法、疑问并随书保存；笔记不会发给 API。
- “全文搜索”会在本设备已导入的所有书籍正文中搜索，结果可直接跳转到对应书籍、章节和段落；搜索完全本地运行，不调用 API。
- 以上内容仍然只保存在浏览器本地。更新 Cloudflare Pages 后如果没看到新按钮，请使用 Ctrl + F5 强制刷新。
